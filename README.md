# 肺鼠疫疫情实时监测与风险研判平台（模拟演示）

一个纯前端、零构建的疫情监测指挥大屏 Demo：**实时统计肺鼠疫发病人员病情严重程度、区域分布，回放发病人员行动时间轨迹，并研判其对应区域在该时段的疫情风险**。

> ⚠️ 免责声明：本平台为公共卫生信息化教学演示系统，底图为高德官方深色矢量地图（JS API 2.0），行政区划为**真实地理数据**（全国 34 个省级行政区，DataV.GeoAtlas 省界已本地化到 `vendor/china-provinces.js`；市/区县边界与乡镇/街道位置按需在线加载）；病例数据仅由后台人工录入，**不代表任何真实疫情**。

## 快速开始

```bash
cd plague-dashboard
python -m http.server 8377
# 浏览器打开 http://127.0.0.1:8377/
```

依赖库（ECharts、Leaflet、leaflet.heat、全国省级行政区划）已全部本地化在 `vendor/`，**内网离线可用**（底图瓦片需外网，离线时真实行政区划矢量图层与区名标注仍正常显示）。也可以直接双击 `index.html` 打开。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 顶部指挥栏 | 实时时钟（**时间基准与现实保持一致**，无倍速/暂停）、后台登记入口 |
| KPI 指标卡 | 累计报告、现有在治、重型/危重型、疑似、今日新增、治愈、死亡、当前高风险区域数（全部来自后台人工登记） |
| 疫情地图 | 高德官方深色矢量底图（村镇级地名）；行政区划**逐级下钻：全国 → 省 → 市/区县 → 乡镇/街道**（点击区域下钻，⬆ 返回上一级，面包屑导航）；各层级按"当前时段风险 / 现有病例 / 累计病例"着色（街镇层为真实位置点圈）；病例点大小=严重程度（虚线圈=疑似）；近 6 小时暴露热力图 |
| 严重程度分布 | 现有在治病例按 疑似/轻型/普通型/重型/危重型 玫瑰图 |
| 实时播报 | 登记上报、确诊、病情调整、治愈、死亡事件流（重大事件 Toast 弹窗）——事件仅来源于后台人工操作 |
| 趋势与区域 | 近 14 天按发病日期×严重程度堆叠柱、各区域累计堆叠柱 |
| 风险矩阵 | 区域 × 2 小时时段的疫情风险等级热力矩阵（今日/昨日切换，悬停显示风险分）；**随地图视野联动**——放大/平移地图时矩阵自动聚焦当前视野内区域；当视野中心区域占据视口主体（面积交叠 ≥35%，或街道级深放大按最近中心）时矩阵**随目标区域逐级递归下钻**——构建聚焦链（如 上海市 › 徐汇区 › 田林街道）：每级加载其下级区划（省/市→DataV 边界；区县→村镇 POI），继续判定更深一级聚焦，直至叶级街道；矩阵按病例轨迹真实位置归集计算**聚焦链末端下级各区域的分时段风险**（标题显示“聚焦：上海市 › 徐汇区 · 下辖 N 个区域”），缩放即逐级进退，否则显示视野内区域集合（“当前视野 n/m”），高度自适应 |
| 病例一览 | 按区域/严重程度/状态/关键字筛选，点击行查看轨迹 |
| 轨迹回放 | 右侧抽屉展示病例档案 + 全部停留点（时间、场所、区域、该时段该区域风险等级）；地图同步动画回放，可播放/暂停/拖动进度条/点击任意停留点跳转，支持导出 JSON |
| 后台登记入口 | 顶栏"🛠 后台登记"进入后台：**实时登记病人信息**（人口学、发病时间、初步病情、疑似/确诊，可自动生成演示轨迹）与**变更病人状态**（确诊、严重程度调整、治愈、死亡登记，即时生效并进入实时播报）；**链式传染路径**可多填无上限，每环节 = 时间 + 该时间段所在具体区域（可附场所/备注），保存后形成"时间·区域 → 时间·区域 → …"的链式路径，在病例表、轨迹抽屉按环节展示该时段该区域疫情风险，并在地图上以红色编号标记 + 虚线连线叠加显示；操作日志按场景种子持久化到 localStorage，刷新后自动重放；"清除记录"可整体移除 |

## 数据录入与风险模型

- **病人病例只能由后台手动输入**：系统空库启动，不自动生成任何病例（含历史疫情）；全部病例经「后台登记 → 实时病例登记」录入（人口学、发病时间、初步病情、疑似/确诊、链式传染路径、可选演示轨迹），登记即上报并立即计入统计、地图与风险模型。
- **病人状态变更只能由后台人员手动操作**：确诊、严重程度调整（轻/普通/重/危重）、治愈、死亡均经后台登记，系统不自动变更。
- 手工登记与变更持久化到浏览器 localStorage（按种子键隔离，默认 20261010），刷新后按登记时刻自动重放；「清除记录」可整体移除。
- **风险分** = Σ（场所人群系数 × 传染性系数 × 停留时长），按 *区域 × 2 小时时段* 归集。等级：低 ≤2.5 < 中 ≤6 < 较高 ≤11 < 高 ≤18 < 极高。

## 技术说明

- 无构建步骤、无框架依赖，普通 `<script>` 加载（file:// 直开兼容）。
- **接入全中国地图（高德 JS API 2.0）**：官方深色矢量底图（Key 已内置，支持村镇级地名与 3-20 级缩放）；全国 34 个省级行政区真实边界本地分发（DataV，含港澳台），**市/区县级边界按需从 DataV 在线加载并简化**；**乡镇/街道级通过高德 WebService POI 检索真实街道办/镇政府位置**（JSONP，无需安全密钥）作为村镇层；病例按居住坐标自动归入当前层级区域（点包含 + 最近中心回退）；209 个真实地标场所（上海市全域 76 处按真实区县绑定 + 各省会地标）；演示轨迹集中于所在区域生成。
- **行政区划下钻与精度**：全国（省级）→ 省（市/直辖市区县）→ 市（区县）→ 区县（乡镇/街道，POI 点位）；登记"现住区域"、链式传染路径、区域分布图、风险矩阵（区域×2小时时段）全部随当前层级自动切换，实现村镇级防疫精度；下钻数据内存缓存，重复进入即时加载。
- **时间基准与现实保持一致**：平台时钟每 250ms 与现实时间同步（直接取当前时间，不累积推进，杜绝节流/休眠漂移）；登记与变更即录即显，刷新后历史数据立即可见。
- 每 1s 全量刷新聚合视图；病例点采用增量 diff 更新。
